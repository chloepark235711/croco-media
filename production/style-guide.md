# Croco's Little World — 제작 스타일 가이드 (공개용)
- 형식: YouTube Shorts, 세로 9:16, 720p, 장면당 3–30초 (Kling 4.0 text-to-video).
- 주인공: 초록색 아기 악어 Croco (둥근 눈, 노란 배, 빨간 스카프). 모든 프롬프트에 동일한 외형 문장을 넣어 일관성 유지.
- 톤: 따뜻함, 천천히, 밝은 색, 폭력·공포·위험 행동 모방 금지.
- 에피소드당 교육 목표 1개 (예: 나눔, 정리, 기다림, 숫자, 색깔).
- 금지: 기존 캐릭터·브랜드·노래·상표, 실존 인물, 개인정보, 제품 광고.
- 공개 저장소 금지 정보: API 키, 예산·재무·승인 기록 (비공개 저장소 croco-control에만).
